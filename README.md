Campus app
Overview

Campus app is a comprehensive platform designed to enhance communication, collaboration, and management within a university campus. It provides various features tailored to different user roles, including:

Student: Access to the canteen menu, chat functionality, and assignment deadlines.
Teacher: Ability to post assignments and deadlines, manage assignments, and view student grades.
Canteen Staff: Ability to add items to the menu, manage item availability, and view canteen statistics.
Key Features

User Role Management: Students, teachers, and canteen staff can access the platform based on their roles.
Chat and Messaging: Students can chat with other students, teachers, and canteen staff in real-time.
Group Chat: Teachers and canteen staff can create and manage group chat sessions.
Canteen Menu Management: Canteen staff can add items to the menu, manage item availability, and view canteen statistics.
Assignment and Deadline Posting: Teachers can post assignments and deadlines, manage assignments, and view student grades.
How to Use the Platform

Sign Up and Log In: Access the platform using your credentials.
Select Role: Choose your user role when signing up.
Explore Features: Utilize the chat, group chat, canteen menu, and assignment/deadline features as per your role.
Report Issues: If you encounter any issues, report them via the contact information provided on the platform.
